Polyglot Blocks

The defining feature of the Block programming language is its ability to embed other programming languages seamlessly. This is done using XML-style tags.

Supported Languages

The Orchestrator currently ships with built-in support for the following languages via tags:

  • <py> ... </py> - Python (requires python in PATH)
  • <js> ... </js> - JavaScript (requires node in PATH)
  • <php> ... </php> - PHP
  • <cpp> ... </cpp> - C++ (requires GCC / G++)
  • <go> ... </go> - Go

Automatic State Sharing

When execution enters a language block, the Orchestrator automatically injects all native variables into that language's execution context. When the block finishes, any modifications made to those variables are captured and synced back to the global state.

Example: Python and JavaScript

counter = 100

<py>
# This is a Python block
import math
counter = counter + math.floor(5.5)
print(f"Python updated counter to: {counter}")
</py>

<js>
// This is a JavaScript block
// 'counter' starts at 105 based on the Python execution
counter = counter * 2;
console.log(`JavaScript updated counter to: ${counter}`);
</js>

print("Final result in Block:", counter)

Syntax Rules Inside Blocks

Inside a language block, you are writing native code for that specific language. You must obey all rules of that language.

  • In a <py> block, you must respect Python's indentation rules.
  • In a <js> block, you should use JavaScript syntax (e.g., semicolons, var/let/const for local variables).

Note: If you declare a new variable inside a block using a local keyword (like let temp = 1; in JS), it will not be synced back to the global Block state. Only variables initialized in the native Block scope, or explicitly exported, are tracked.
