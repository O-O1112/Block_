Introduction

Welcome to the official documentation for Block, a revolutionary interpreted programming language designed specifically for seamless polyglot orchestration.

The Core Philosophy

Modern software development often requires mixing multiple languages to achieve the best results. For example, you might want to use Python for its rich data science libraries, JavaScript for its asynchronous web capabilities, and C++ for high-performance number crunching.

Traditionally, bridging these languages requires complex architectures such as microservices, REST APIs, or cumbersome inter-process communication (IPC) protocols. This introduces latency, serialization overhead, and significant architectural complexity.

The Block Solution

Block solves this problem by allowing you to mix multiple programming languages within a single file. The underlying C# Orchestrator automatically handles state sharing, memory synchronization, and secure data passing between different language execution contexts.

  • Single File Polyglot: Write Python, JavaScript, and PHP in the same .blk script.
  • Automatic State Sharing: Variables mutated in a Python block are instantly accessible in the subsequent JavaScript block.
  • No Virtual Machine: Block doesn't emulate execution. It routes AST nodes to native interpreters (like python.exe or node.exe), ensuring 100% standard library compatibility and zero VM overhead.
