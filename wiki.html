Block 語言官方文件

Block 是一個專注於「多語言混合開發」的直譯式程式語言。它允許你在同一個專案、甚至同一個檔案內混合使用 Python、JavaScript、C++ 等多種語言，並在底層自動共享變數狀態。

1. 核心設計理念

現代開發常遇到需要混用多種語言的場景，通常需要透過 API 或子行程來溝通，導致專案架構變得複雜。

Block 透過底層的狀態共享機制解決了這個問題。在 .blk 檔案中，不同語言的區塊可以直接存取並修改同一個變數，省去了跨語言通訊的開發與序列化成本。

2. 環境安裝與執行

環境需求

  • Node.js (執行 Block 核心所需的環境)
  • 若要使用特定語言的區塊，需具備對應環境（例如本機需安裝 Python 3, Go, GCC 等）

執行腳本

node ./bin/block.js run script.blk

3. Block 原生語法

原生 Block 負責基礎的邏輯控制與變數指派。它的語法設計極度精簡，不強制要求縮排，也不使用大括號 {}，而是統一使用 block 作為控制結構的結束點。

變數宣告與輸出

age = 25
name = "Alice"
print("Name:", name, "Age:", age)

控制結構

if age >= 18:
    print("Adult")
elif age > 12:
    print("Teen")
else:
    print("Child")
block

4. 多語言區塊 (Polyglot Blocks)

你可以使用類似 XML 的標籤來嵌入其他程式語言。變數會在進入區塊前自動注入，並在區塊結束後將更新的值傳回原生 Block。

目前支援的語言標籤包含：<py>、<js>、<cpp>、<go>、<java>。

範例：跨語言變數共享

x = 100

<py>
# 在 Python 區塊中，可以直接讀取與修改 x
import math
x = x + math.floor(5.5)
print("Python 處理後:", x)
</py>

<js>
// 接著進入 JS 區塊
x = x * 2;
console.log("JS 處理後:", x);
</js>

print("最終結果:", x)
block

5. 錯誤處理與安全機制

  • 狀態檔案通訊：底層使用 .state.json 作為跨進程通訊媒介。
  • 變數名稱過濾：跨語言傳遞前，引擎會以正規表達式驗證變數名稱，阻擋惡意指令碼注入。
  • 終端機錯誤提示：當語法或執行期發生錯誤時，Block 會在終端機印出高反差的 BSOD 錯誤提示方塊，標明錯誤發生的語言區塊。
