Installation & Quick Start

Setting up the Block environment on your machine is incredibly straightforward thanks to our dedicated Windows Installer. It automatically sets up the Orchestrator engine and provisions all the necessary runtime environments for polyglot execution.

System Requirements

  • OS: Windows 10 or Windows 11 (64-bit)
  • Storage: 250MB free space (for the orchestrator and bundled runtimes)
  • Node.js: v16.0.0 or newer (Required for JavaScript block orchestration)

Installing via the Official Installer

We provide a standalone executable installer that registers the block command globally.

  1. Download the installer from the homepage: BlockSetup.exe
  2. Run the executable as an Administrator.
  3. The installer will automatically download the required standard runtimes (such as Python 3.10 and PHP 8.1) and link them to the Orchestrator.
  4. Once finished, restart your terminal to reload the system PATH.

Verifying the Installation

To verify that Block is installed correctly, open a new Command Prompt or PowerShell and type:

block --version

You should see an output showing your installed engine edition, for example: Block Language Engine v2.0.0 (Standard Edition).

CLI Commands & Flags Reference

  • block [script.blk] — Executes a Block script file.
  • block --version / -v — Displays version and edition details.
  • block --help / -h — Displays usage information and the ASCII logo.
  • block serve [port] — Starts the built-in HTTP Web & API Server.
  • block config — Opens the interactive settings CLI.
  • block-plus fmt [script] — (Block+ Only) Formats polyglot code blocks.
  • block-plus check [script] — (Block+ Only) Runs cross-language static analysis.

Writing your first Block script

Create a new file named hello.blk and add the following polyglot code:

<py>
msg = "Hello from Python!"
</py>

<js>
console.log(msg); // Shared state
</js>

Run the script using the CLI:

block hello.blk
