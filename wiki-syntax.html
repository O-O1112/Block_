Native Syntax

The native syntax of Block is designed to act as the "glue" between your polyglot blocks. It intentionally keeps logic minimal, focusing on orchestration, variable declarations, and simple control flow.

The "No Braces, No Indentation" Philosophy

Unlike Python, Block does not use strict indentation. Unlike C-based languages, it does not use curly braces {}. Instead, Block uses a unique keyword termination system. Every control structure is opened with a colon : and explicitly closed with the keyword block.

Variable Declaration

Variables are implicitly typed and do not require keywords like var or let.

name = "Alice"
age = 28
score = 99.5

print("User:", name, "Age:", age)

Control Structures

If / Else

Conditional branching uses standard if, elif, and else, terminating with block.

if age >= 18:
    print("Status: Adult")
elif age > 12:
    print("Status: Teenager")
else:
    print("Status: Child")
block

While Loops

counter = 0
while counter < 5:
    print("Count is:", counter)
    counter = counter + 1
block

Functions

Native functions can be defined using the func keyword. They are useful for organizing basic orchestration logic.

func calculateTax(amount):
    tax = amount * 0.05
    return amount + tax
block

total = calculateTax(100)
print("Total after tax:", total)
